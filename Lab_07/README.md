## Что сделано
Проанализированы готовые чанки, реализованы три стратегии разбиения документов,
посчитаны метрики cosine/euclidean/cityblock/dot, выполнена L2-нормализация,
проверена формула |a-b|² = 2-2cos, применён StandardScaler, выполнен поиск по чанкам
с оценкой качества, сделаны выводы. Дополнительно: L1 vs L2 нормализация и PCA-визуализация.
