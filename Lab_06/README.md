# Лабораторная работа №6. Лемматизация и векторизация текстов

**ФИО:** Ушакова Марина Михайловна  
**Группа:** ЕТ-212

## Что сделано
В рамках лабораторной работы был обработан корпус из 25 отзывов о фильмах (`reviews.csv`). 
Выполнена очистка текстов от шума (ссылки, HTML, хэштеги, цифры) с помощью регулярных выражений и последующая лемматизация с использованием библиотеки `pymorphy3`. 
Построены модели «мешка слов» (Bag of Words) и TF-IDF с использованием униграмм и биграмм, проведено сравнение их размерностей и влияния фильтров (`min_df`, `max_df`). 
Также проведен разведочный анализ данных (EDA): визуализация частотности слов и длин документов, расчет матрицы косинусного сходства для поиска наиболее похожих и непохожих отзывов. 
В качестве бонусного задания выполнено снижение размерности TF-IDF-матрицы с помощью метода главных компонент (PCA) и визуализирована кластеризация отзывов по оценкам (rating).
